## Changelog Update

After step 3 binds the review and security statuses and before the ship commit, add this branch's changes to an existing `CHANGELOG.md` under `## [Unreleased]`. Never create the file. Read `## [Unreleased]` first. Add no bullet for a change it already lists, so a rerun with no new change leaves the file untouched. In multi-repo mode, update each repo's file with only that repo's entries.
