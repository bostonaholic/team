# Record The Assumption

A principle, not a gate. Work resolved on incomplete information carries a
guess, and an unmarked guess is a defect — not because guessing is wrong, but
because a guess that reads as a settled fact cannot be audited. Mark it,
name the alternative it displaced and the trade-off accepted, and put the mark
where whoever audits the work will actually look. Deferral is itself a
recorded choice, and it gets the same treatment.

## What it rules out

- **A guess written as a finding.** Prose that states an inference in the same
  voice as a verified fact leaves the reader unable to tell them apart.
- **An assumption recorded somewhere the auditor does not read** — a scratch
  note, a chat message, a comment on a line nobody opens.
- **A silent deferral.** Dropping an item quietly is a decision that leaves no
  record, and the next reader has no way to know it was considered.
- **A mark with no content.** "Assumption" as a bare label records that
  something was assumed and none of what would let a reader check it.
- **An absorbed ambiguity.** A delegate that hits an open question and neither
  resolves it on the record nor surfaces it has removed the question from
  everyone's view but its own.

## Boundary

- It governs what a recorded guess must look like. Whether to resolve a
  question yourself or route it elsewhere is a separate call that each
  procedure makes on its own terms, and this rule takes no position on it.
- It does not turn every choice into an assumption. A choice the inputs
  determine is a derivation, and marking it as a guess dilutes the marks that
  matter.
- Recording an assumption is not the same as validating it. The mark exists so
  someone can check it later, and it makes no claim that anyone has.
