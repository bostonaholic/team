# Record Assumptions

Resolve genuine choices during autonomous steps with the option you would recommend, and record each explicitly; An unmarked guess is a defect.

- Mark the governing artifact with "Assumption — chosen without user review".
- Name the rejected alternative and accepted trade-off.
- Absorb ambiguity upward: record helper ambiguity in your artifact's open questions or resolve and record it; never delegate asking.
- Record low-stakes deferrals as deferred open questions instead of expanding the decision list.
- Report the artifact's assumption count.
